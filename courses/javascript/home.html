As três armadilhas do JavaScript

Saber estas três resolve a maioria das perguntas "o que aparece no ecrã?".

1. O + com texto junta, os outros operadores convertem. "5" + 3 dá "53", mas "5" * 3 dá 15. Converte de propósito com Number(...).

2. Usa sempre ===. O == converte tipos antes de comparar e dá resultados estranhos (0 == false é verdade).

3. Objetos e arrays são referências. const b = a não copia: as duas variáveis apontam para o mesmo objeto. Copia com [...a] ou { ...a }.

Onde praticar

  • Sem instalar nada: abre as ferramentas do browser (F12), vai ao separador Consola e escreve JavaScript diretamente. Os objetos aparecem um pouco diferentes do Node, mas os valores são os mesmos.
  • No teu computador: instala o Node.js, escreve o programa num ficheiro ola.js e corre node ola.js.
  • Para as lições do DOM, escreve um ficheiro HTML com um <script> no fim do body e abre-o no browser. Os erros aparecem na consola (F12).

Para quem está a explicar

  • Pede-lhe que diga o que aparece no ecrã antes de carregar em "Seguinte", sobretudo nas lições 1 e 7.
  • Quando um valor sai estranho, usem console.log(typeof x, x): quase sempre é texto onde se esperava um número.
  • Nas lições 4 a 7, desenhem as variáveis e os objetos com setas, como o visualizador.
  • Nas lições do DOM, abram a consola do browser juntos: os erros dizem a linha e o que estava null ou undefined.
