Antes de entregar

  • As comparações usam === e !==.
  • Os valores que vêm de campos ou de texto foram convertidos com Number antes das contas.
  • Usas const por omissão e let só onde a variável muda; nunca var.
  • As funções que devem devolver um valor têm return.
  • Os sort de números têm a função (a, b) => a - b.
  • Onde querias uma cópia de um array ou objeto, fizeste uma ([...v], { ...o }).
  • Nos eventos, passaste a função sem a chamar (sem parênteses).
  • A consola do browser (F12) não mostra erros.
