Funções

def media(lista):
    return sum(lista) / len(lista)

def mostra(x):       # sem return: devolve None
    print(x)

O parâmetro aponta para o mesmo objeto que o argumento: se a função muda uma lista recebida, a mudança vê-se fora.

Antes de entregar

  • Os if, for, while e def acabam com : e o bloco tem 4 espaços.
  • O que vem do input foi convertido antes das contas.
  • As divisões usam / ou // conforme queres real ou inteiro.
  • Os range acabam onde devem (o último número não está incluído).
  • Onde precisavas de uma cópia de uma lista, usaste .copy().
  • As funções que devem devolver um valor têm return (e não só print).
  • Testaste com valores pequenos e casos limite (0, lista vazia, chave que não existe).
