Ciclos

}

Funções

int soma(int a, int b) {         // devolve um int
    return a + b;
}

void mostra(int x) {             // não devolve nada
    printf("%d\n", x);
}

void dobra(int *x) {             // muda a variável de quem chama
    *x = *x * 2;
}
// chamar: dobra(&n);

    printf("Erro ao abrir\n");

Antes de entregar

  • Todas as instruções acabam em ; e as chavetas estão fechadas.
  • Todas as variáveis têm valor antes de serem usadas (acumuladores a 0).
  • Os scanf têm & (exceto strings) e o formato certo (%lf para double).
  • As comparações usam ==, não =.
  • As divisões que precisam de casas decimais têm um real (3.0).
  • Os ciclos sobre arrays vão de 0 até < tamanho.
  • Cada case do switch tem break.
  • Testaste com valores pequenos e casos limite (0, negativos, o último elemento).
