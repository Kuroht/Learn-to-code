Antes de entregar

  • O npm run build não dá erros de tipos, e a consola do browser não tem avisos.
  • Cada item de uma lista tem uma key estável (o id).
  • O estado só muda pelo setter, e sempre com um array ou objeto novo.
  • Nada em estado que se possa calcular a partir de outro estado ou das props.
  • O estado vive no componente mais abaixo que o use (ou no pai comum, se forem vários).
  • Os dados carregados têm os estados a carregar, erro e vazio.
  • Cada componente faz uma coisa e cabe no ecrã.
