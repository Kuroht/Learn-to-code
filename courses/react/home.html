Aprender React a construir uma app de tarefas

Onze lições curtas. Cada uma acrescenta uma peça à mesma app: componentes, props, listas, estado, formulários, filtros e efeitos. Em cada exemplo a app corre a sério ao lado do código, e vês que componentes renderizam cada vez que carregas num botão.

Como usar

  1. Lê a explicação

    É curta e assume que já fizeste o JavaScript e o TypeScript do Zero. As linhas a verde no código são as novas desde a lição anterior.

  2. Corre o exemplo

    Em cada "Seguinte", o curso carrega nos botões e escreve nos campos por ti. Antes, pergunta-te: o que muda na app? Quem renderiza?

  3. Mexe na app

    A app do exemplo é verdadeira: podes carregar nos botões e escrever nos campos. O painel "Componentes" atualiza-se no passo seguinte.

  4. Faz os exercícios no computador

    Cria um projeto com npm create vite@latest (React + TypeScript), escreve o src/App.tsx e corre npm run dev.

A ideia em que tudo assenta

No curso de JavaScript mudavas a página à mão. Em React descreves a página para os dados de agora.

Um componente é uma função: recebe dados (props e estado) e devolve o que deve aparecer. Quando o estado muda, o React volta a chamar a função e atualiza só o que ficou diferente.

Por isso quase tudo o que corre mal num principiante vem de uma de três coisas: mudar dados sem o setter, mudar um array ou objeto por dentro (o React acha que é o mesmo), ou guardar em estado o que se podia calcular.

O painel "Componentes" mostra isto a acontecer: a amarelo, quem renderizou no último passo.

Onde praticar

  • No teu computador: com o Node instalado, npm create vite@latest tarefas -- --template react-ts, depois cd tarefas, npm install e npm run dev. Abre o endereço que aparece no browser.
  • O CSS das apps do curso está na cábula: copia-o para o src/App.css.
  • Instala as React DevTools no browser: o separador "Components" é o painel deste curso, mas para a tua app.

Para quem está a explicar

  • Antes de cada passo com uma ação, pede-lhe que diga que componentes vão ficar a amarelo.
  • O exemplo do push (lição 6) vale a pena fazer devagar: é o bug mais comum, e liga-se às referências do JavaScript.
  • Perante cada estado novo, perguntem: "isto podia ser calculado a partir de outra coisa?"
  • A consola do browser (F12) mostra os avisos do React, como as keys em falta: habituem-se a tê-la aberta.
