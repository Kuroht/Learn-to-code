Tudo o que as lições ensinam, numa página. Boa para ter aberta enquanto fazes exercícios.

Uma consulta completa

SELECT curso, COUNT(*) AS n      -- 5. colunas
FROM alunos                      -- 1. tabela
WHERE nota >= 10                 -- 2. linhas
GROUP BY curso                   -- 3. grupos
HAVING COUNT(*) >= 2             -- 4. grupos que ficam
ORDER BY n DESC                  -- 6. ordem
LIMIT 3;                         -- 7. quantas

Os números dizem a ordem em que o SGBD trabalha.

Criar e mudar dados

CREATE TABLE alunos (
    numero INTEGER PRIMARY KEY,
    nome TEXT NOT NULL,
    curso TEXT REFERENCES cursos(sigla),
    nota INTEGER
);
INSERT INTO alunos VALUES (101, 'Ana', 'LEI', 17);
INSERT INTO alunos (numero, nome) VALUES (102, 'Rui');
UPDATE alunos SET nota = nota + 1 WHERE numero = 102;
DELETE FROM alunos WHERE nota < 10;
DROP TABLE alunos;               -- apaga a própria tabela

UPDATE e DELETE sem WHERE afetam todas as linhas. Testa o WHERE primeiro com um SELECT.

Condições (WHERE e HAVING)

= <> != < > <= >=comparar (igual é um só =)
AND OR NOTe, ou, não (usa parênteses)
BETWEEN 10 AND 14inclui o 10 e o 14
IN ('LEI', 'LEM')igual a um destes
LIKE 'M%'% qualquer texto, _ um carácter
IS NULL, IS NOT NULLnunca = NULL

Texto entre plicas: 'LEI'. As aspas são para nomes de colunas.

Funções de agregação

COUNT(*)número de linhas
COUNT(col)linhas com valor (sem os NULL)
COUNT(DISTINCT col)valores diferentes
SUM AVG MIN MAXsoma, média, menor, maior (ignoram NULL)
ROUND(x, 2)arredonda a 2 casas
COALESCE(x, 0)x, ou 0 se x for NULL

Inteiro / inteiro dá inteiro, como em C: 7 / 2 é 3. Usa AVG ou 7 / 2.0.

JOIN

-- só as linhas com par
SELECT a.nome, c.nome AS curso
FROM alunos a
JOIN cursos c ON a.curso = c.sigla;

-- todas as da esquerda; sem par fica NULL
SELECT a.nome
FROM alunos a
LEFT JOIN inscricoes i ON i.aluno = a.numero
WHERE i.aluno IS NULL;           -- "quem não tem nenhuma"

Chaves e relações

Chave primária (PK)identifica a linha; única e não NULL
Chave estrangeira (FK)guarda a PK de uma linha de outra tabela
1:NFK no lado N (alunos.curso)
N:Mtabela de ligação com as duas FK; PK = o par
SQLitePRAGMA foreign_keys = ON; para as FK serem verificadas

Formas normais

1FNum valor por célula (nada de listas)
2FNo que não é chave depende da chave toda
3FNo que não é chave não depende de outra coluna que não é chave

Quando falha: tira essas colunas para uma tabela nova e deixa uma FK.

Antes de entregar

  • O texto está entre plicas e as colunas sem nada.
  • Os UPDATE e DELETE têm WHERE (e testaste-o com um SELECT).
  • Os NULL são testados com IS NULL.
  • Com GROUP BY, o SELECT só tem colunas do grupo e funções.
  • As condições sobre funções estão no HAVING, não no WHERE.
  • Num JOIN, há um ON certo e as colunas repetidas levam a alcunha da tabela.
  • Para "quem não tem", usaste LEFT JOIN e IS NULL.
  • Se a ordem interessa, há ORDER BY.
