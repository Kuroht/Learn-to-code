Cábula de TypeScript

Tudo o que as lições ensinam, numa página. Boa para ter aberta enquanto fazes exercícios.

Tipos básicos

let nome: string = "Ana";
let idade = 19;                 // inferido: number
const ativo: boolean = true;
let nada: undefined;
let qualquer: any;              // evita
let lista: number[] = [1, 2];   // ou Array<number>
let par: [string, number] = ["Ana", 17];

Funções

function area(l: number, a: number): number {
  return l * a;
}
const dobro = (x: number): number => x * 2;
function ola(nome: string, pontos?: number): string { ... }
function mostra(t: string): void { console.log(t); }

Objetos

interface Aluno {
  nome: string;
  nota: number;
  email?: string;           // opcional
  readonly numero: number;  // não muda
}
type Ponto = { x: number; y: number };
const a: Aluno = { nome: "Ana", nota: 17, numero: 101 };

Uniões e estreitamento

let v: number | string;
type Tema = "claro" | "escuro";

if (typeof v === "number") { v.toFixed(2); }
else { v.toUpperCase(); }

const r = lista.find(x => x > 10);  // number | undefined
if (r !== undefined) { ... }
r?.toFixed(1)        // undefined se não houver r
r ?? 0               // 0 se não houver r

Classes

interface Forma { area(): number; }

class Quadrado implements Forma {
  private lado: number;
  readonly nome = "quadrado";
  constructor(lado: number) { this.lado = lado; }
  area(): number { return this.lado * this.lado; }
}

Genéricos e async

function primeiro<T>(v: T[]): T | undefined {
  return v[0];
}
interface Caixa<T> { valor: T; }

async function nota(id: number): Promise<number> { ... }
async function principal(): Promise<void> {
  try {
    const n = await nota(101);
  } catch (e) {
    console.log((e as Error).message);
  }
}

Antes de entregar

  • O tsc --strict não dá nenhum erro.
  • Não há any (nem ! para calar o compilador) sem uma boa razão escrita num comentário.
  • Todos os parâmetros das funções têm tipo.
  • Os objetos têm uma interface ou um type, e os valores fixos têm um tipo literal.
  • O que pode ser undefined (o find, campos opcionais) é testado antes de usar.
  • As funções async são esperadas com await, dentro de try/catch.
  • Os dados de fora (formulários, servidores) são convertidos e verificados: os tipos não existem a correr.
