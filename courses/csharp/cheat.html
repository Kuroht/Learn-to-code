Classes

class Aluno
{
    private int nota;                 // campo escondido
    public string Nome { get; set; }  // propriedade

    public Aluno(string nome)         // construtor
    {
        Nome = nome;
    }

    public int Nota
    {
        get { return nota; }
        set { if (value >= 0) nota = value; }
    }
}
Aluno a = new Aluno("Ana");

Herança e interfaces

class Animal
{
    public virtual string Som() { return "..."; }
}
class Cao : Animal
{
    public override string Som() { return "Au"; }
}

interface IForma { int Area(); }
class Quadrado : IForma
{
    public int Lado;
    public int Area() { return Lado * Lado; }
}

Antes de entregar

  • As instruções estão no topo, os métodos a seguir e as classes no fim.
  • Todos os objetos foram criados com new antes de serem usados.
  • Onde querias uma cópia de um objeto, criaste um objeto novo (b = a não copia).
  • Os campos que não devem ser mexidos de fora são private.
  • Os métodos substituídos têm virtual na mãe e override na filha.
  • Cada case do switch tem break.
  • As divisões que precisam de casas decimais têm um double.
