Básico

fn main() {
    let x = 5;              // imutável
    let mut y = 10;         // pode mudar
    y += x;
    let x = x * 2;          // sombrear: outra variável
    println!("{x} {}", y);
    let d = 7 as f64 / 2.0; // conversões com as
}

Structs e enums

#[derive(Debug)]
struct Conta { titular: String, saldo: i32 }

impl Conta {
    fn new(t: &str) -> Conta { Conta { titular: String::from(t), saldo: 0 } }
    fn saldo(&self) -> i32 { self.saldo }
    fn depositar(&mut self, v: i32) { self.saldo += v; }
}
let mut c = Conta::new("Ana");
println!("{:?}", c);

enum Forma { Quadrado(i32), Retangulo(i32, i32) }

Antes de entregar

  • As variáveis que mudam têm mut (e as outras não).
  • Nenhuma variável é usada depois de ser movida.
  • As funções que só leem recebem &, não a posse.
  • A última linha das funções que devolvem um valor não tem ;.
  • Os match tratam todos os casos.
  • Os unwrap() que sobraram estão em sítios onde o valor existe mesmo.
  • Os textos lidos do teclado levam trim() antes do parse.
