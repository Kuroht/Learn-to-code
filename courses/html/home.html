Aprender HTML e CSS a ver a página a nascer

Onze lições curtas, da primeira etiqueta ao flexbox e às páginas que se adaptam ao telemóvel. Em cada exemplo carregas em "Seguinte" e vês a página a mudar, a árvore DOM e o tamanho de cada caixa.

Como usar

  1. Lê a explicação

    É curta de propósito. Fica com a ideia principal e passa ao exemplo.

  2. Corre o exemplo

    Antes de cada "Seguinte", tenta adivinhar como a página vai ficar. O contorno amarelo mostra de que elemento se fala.

  3. Responde às perguntas

    "De que cor fica?", "que largura tem?", "quantos elementos há?". As respostas foram medidas num browser a sério.

  4. Faz os exercícios no computador

    Escreve o ficheiro, abre-o no browser e compara com o resultado esperado antes de veres a solução.

HTML e CSS: quem faz o quê

A separação que torna tudo mais fácil.

O HTML diz o que cada coisa é: um título, um parágrafo, um menu, um formulário. O CSS diz que aspeto tem: cor, tamanho, espaços, posição.

Por isso escolhes o elemento HTML pelo significado (um <h2> porque é um subtítulo) e mudas o aspeto no CSS (mesmo que o queiras pequeno e azul).

Quando uma regra de CSS "não funciona", faz três perguntas: o seletor encontra o elemento? Há outra regra mais específica a ganhar? A declaração está bem escrita (com ; e unidade)?

QueresUsa
um títuloHTML: <h1>
texto vermelhoCSS: color: red
uma listaHTML: <ul> e <li>
caixas lado a ladoCSS: display: flex
espaço à voltaCSS: padding / margin

Onde praticar

  • No teu computador: escreve um ficheiro index.html num editor (o VS Code, por exemplo) e abre-o no browser. Depois de cada mudança, guarda e atualiza a página (F5).
  • No browser, sem instalar nada: CodePen, com o HTML e o CSS em caixas separadas e a página a atualizar sozinha.
  • Carrega em F12 em qualquer página para abrir as ferramentas do browser: mostram a árvore DOM, as regras de cada elemento e o modelo de caixa, como o visualizador.

Para quem está a explicar

  • Pede-lhe que diga como a página vai ficar antes de carregar em "Seguinte", sobretudo nas lições da cascata e do modelo de caixa.
  • Usem as ferramentas do browser (F12) juntos: ver qual regra ganhou e porquê ensina mais do que qualquer explicação.
  • No modelo de caixa, façam as contas no papel antes de ver o inspetor.
  • Lembra que o CSS não dá erros: se nada muda, há um engano silencioso para encontrar.
