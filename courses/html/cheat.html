Cábula de HTML e CSS

Tudo o que as lições ensinam, numa página. Boa para ter aberta enquanto fazes exercícios.

Esqueleto de uma página

<!DOCTYPE html>
<html lang="pt">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>Título do separador</title>
  <link rel="stylesheet" href="estilo.css">
</head>
<body>
  ...
</body>
</html>

Modelo de caixa

conteúdoo width e o height (por omissão)
paddingdentro da borda, com o fundo
bordera borda
marginfora da borda, transparente

Largura total = width + padding + borda (dos dois lados). Com box-sizing: border-box, é só o width.

Flexbox

.pai {
  display: flex;
  gap: 20px;
  flex-direction: row;            /* ou column */
  justify-content: space-between; /* center, flex-start... */
  align-items: center;
}
.filho { flex: 1; }               /* ocupa o que sobra */

Unidades e media queries

width: 50%;        /* do pai */
font-size: 2rem;   /* 2 × a letra da página (32px) */
font-size: 1.5em;  /* 1,5 × a letra do pai */

@media (max-width: 600px) {
  nav { display: none; }   /* só em ecrãs estreitos */
}

Quando algo não aparece como esperavas

SintomaCostuma ser
a regra não faz nadafalta um ; ou uma }; propriedade mal escrita; valor sem unidade (20 em vez de 20px)
a regra só funciona em parte dos elementosoutra regra mais específica ganha (vê-a com F12)
o seletor não encontra nadafaltou o . da classe ou o # do id; ou puseste o ponto no HTML
o width não muda nadao elemento é inline: usa inline-block ou block
as caixas não cabem lado a ladoo padding e a borda somam-se ao width: usa border-box
os acentos aparecem trocadosfalta o <meta charset="utf-8">
a imagem não aparececaminho errado no src (maiúsculas contam, e a pasta tem de ser a certa)
no telemóvel fica tudo minúsculofalta o <meta name="viewport">

Antes de entregar

  • Todas as etiquetas que abriste estão fechadas, pela ordem certa.
  • Há um só h1 e os títulos seguem a ordem (h2 dentro de h1, h3 dentro de h2).
  • Todas as imagens têm alt e todos os campos têm label.
  • As ligações para outros sites começam por https://.
  • O CSS está num ficheiro à parte (ou num <style>), não em atributos style.
  • As cores, tamanhos e espaços repetidos estão numa classe, não copiados.
  • Abriste a página num ecrã estreito (F12, modo telemóvel) para ver se se adapta.
