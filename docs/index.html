Aprender a programar, do zero

Cursos curtos e interativos, em português. Em cada exemplo carregas em "Seguinte" e vês o programa a correr linha a linha. Começa pelo C se nunca programaste.

.c C do Zero Do primeiro printf aos apontadores e structs. Para quem nunca programou. .sql SQL do Zero Tabelas, consultas, chaves e JOIN, vendo que linhas passam em cada passo. Para Bases de Dados. .py Python do Zero Para quem já fez o C: nomes que apontam para objetos, listas, dicionários e funções. .cs C# do Zero Para quem já fez o C: pilha e heap, classes e objetos, referências, herança, interfaces e List<T>. .rs Rust do Zero Para quem já fez o C: ownership, move, empréstimos, drop, Option, Result e match.
